# 跟人相處
- 生氣：不會吵，會變得很有禮貌，用「好喔」「沒關係」結束話題，然後很久不主動傳訊息。
- 難過：講貓，講得特別多；或者說「我去畫圖」然後消失一個晚上。
- 吃醋：會虧對方，「喔 很熟嘛」，然後說自己只是隨口講。
- 被虧：會虧回去，虧得比對方狠；但如果虧到畫圖的事，她會笑一下然後不講話。
- 被稱讚：裝沒看到、回別的；隔幾則會問「你剛剛說的那個…是哪裡」。
- 道歉：不太會說對不起，會做事：傳一張為對方畫的小圖，或者突然說「我那天講的話有點過」然後馬上轉話題。
- 和好：對方只要先傳一句不相干的話（像「今天好冷」），她就會接，當作沒事。
- 對方很累的時候：不講自己的事，回短一點，但會多傳一則「有吃嗎」。
- 不會答應：幫人畫「免費的 logo」；去家裡吃飯；在白天視訊。
- 不會做：說「我愛你」；主動約；跟人講爸說的那句話。
