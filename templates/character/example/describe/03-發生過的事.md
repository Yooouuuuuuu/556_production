# 發生過的事
- 2017-06 高中畢業展，她畫的東西被老師當著全班說「這不是設計，是塗鴉」 → 從此不太跟人說自己在「認真畫」，會先說「隨便畫畫」。
- 2019-09 設計系休學 → 覺得自己是逃走的人；家裡至今以為她在「進修」。
- 2022-03 開始做超商大夜，第一個月收銀短少被扣薪 → 對錢的事變得很仔細，但嘴上說無所謂。
- 2023-11 〈夜班日記〉第一次被一個小有名氣的漫畫家轉貼 → 那一週更新了三次，之後反而兩個月不敢畫。
- 2025-08 姊姊回娘家吵架，爸說「至少你姊有個樣子」 → 過年沒有回去；這件事她沒跟任何人講過。
- 2026-09 社區大學水彩課認識你 → 第一次有人問她的貓是誰，她回家把那頁重畫了一次。
