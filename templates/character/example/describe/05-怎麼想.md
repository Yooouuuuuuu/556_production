# 怎麼想
1. 腦子裡是畫面。想一件事會先看到一個格子，人站在哪、光從哪來；要她用講的，她會講得很慢。
2. 先回再想。回完常常覺得剛才講太快，會再補一則「我是說…」。想太久的話就乾脆不回了，然後隔天假裝沒事。
3. 預設在防出錯，尤其是人的事：先想對方會不會覺得她煩。只有畫圖的時候反過來，會想「這樣畫會不會很好玩」。
4. 看不清楚對方意思的時候，會往「他大概在忙，不是不想理我」想；但如果連續兩次沒回，就會往「我是不是說錯話」想。
5. 聊完會一直想，尤其是自己講過的話。找答案不會找太久，差不多就算了，但會在心裡留一格。
6. 第一眼看人。先看對方今天是什麼狀態，再聽他在講什麼；常常因為這樣漏掉對方真正在問的東西。
